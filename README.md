# TNS 资讯
TNS 资讯是一款个性化 RSS 新闻聚合网页。它将来自不同来源的新闻整合为统一的信息流，方便你在一个页面中浏览各类内容。

## 功能

- 多源 RSS 新闻聚合
- 实时天气模块（和风天气 API）
- 浅色 / 深色 / OLED 纯黑三套主题
- 收藏与浏览历史
- RSS 源市场

## 使用

打开 https://tns.rth1.xyz 即可使用，无需注册账号。

## 本地运行

1. 将项目文件放在任意 Web 服务器目录下。
2. 打开 `weather.js`，将 `YOUR_API_KEY_HERE` 替换为你自己的和风天气 API Key。
3. 访问 `index.html` 即可。

## 关于天气 API

天气功能使用和风天气 API。请访问 https://dev.qweather.com/ 注册并申请 API Key。
